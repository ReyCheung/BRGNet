# BRGNet
BRGNet: A Neurophysiology-Informed Band-Region Gated Network for EEG-Based Cognitive Impairment Detection

# Dataset
The data used in this study are publicly available from the following sources: 
ADFTD (https://openneuro.org/datasets/ds004504);
PADIC (https://datadryad.org/dataset/doi:10.5061/dryad.8gtht76pw);
CAUEEG (https://github.com/ipis-mjkim/caueeg-dataset). 
No new data were generated in this study.
